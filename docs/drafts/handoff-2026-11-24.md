## Things that bit this session, so the next one doesn't relearn them

- **Playwright MCP times out after a container restart.** npx downloads the
  package on a cold cache, which takes longer than the 30 s connect limit.
  `/mcp reconnect` isn't available in a cloud session, so only a fresh
  session fixes it (running-thoughts #146, not scoped).
- **A new worktree has no generated state.** Deployment tests read
  `data/<asset>/` (scenario placements, bookkeeping, deliveries) and built
  `reports/<asset>/`.
  - Copy `data/<asset>/` from a worktree that has it. Generation is seeded,
    so the content is identical.
  - Then run `MOTHMAN_ASSET=<asset> mothman dashboard rebuild-results` and
    `build-data` for each asset.
  - Without this, tests fail ("TS-n is not placed") or skip ("not built in
    this checkout").
- **The chunked gate needs a final `-n0 -m unloaded` step.** The
  first-view timing class is deselected under xdist (Keith 2026-11-23: keep
  6 s, run it with no parallel load). `mothman check` and test.yml both do
  this; a hand-rolled chunk script has to add it.
- **The on-demand set is outside the local gate.** Run
  `uv run pytest --run-on-demand -m on_demand` after touching the bootstrap,
  streams or the thirty-linked fixture.
- **A full GitHub run costs about 145 billable minutes on a cache miss.**
  The month to 2026-11-23 is about 1,320 of 2,000. Check
  `GITHUB_REPOSITORY=keithamoss/data-poc mothman github ci-usage` first.
- **A misquote to own:** the session told Keith DASH-277 c5 "sets an 8-name
  cap". It does not; the cap came from the session's own question. The fix
  that mattered was laying the lines out within 80 columns.
- **Keith's sign-off scope stays as CLAUDE.md says.** All signed-wording
  changes this session went to him word for word before landing.
