# Judging a page as its reader

These rules are about how a finished page reads. A reader can apply each one to the page alone, with nothing else open but the glossary.

Whoever writes a page writes to these rules. Whoever reads it as a critic judges it by the same rules. No machine checks them.

## The answer comes first

The first sentence of the 'In short' box answers the page's why-question on its own. A reader who stops after that sentence still leaves with the answer.

## Every page stands alone

A reader can arrive on any page cold, from a link or a search, without having read any other page.

So every invented term the page uses is defined on that page. Every cast member it uses is introduced by name and role, in one clause, on first mention. This holds even when another page or the glossary already does it.

## Stories are about data, never the people in it

Every story concerns files, deadlines, and decisions. It is never about the children, families, or births the data describes.

No page carries a realistic case, or an invented personal detail such as a child's name, a date of birth, or a family circumstance. This holds in a diagram and in an example row too.

A breach of this rule is a blocker.

## A diagram earns its place

A diagram has to argue a point rather than decorate the page. It passes only if it meets both tests:

- With every label stripped away, its shape still carries the idea.
- A reader could learn something from it.

A diagram that adds nothing the prose has not already said is excess.

## Rhetorical tics that follow a pattern

No fixed phrase catches these, so a reader has to spot them:

- A sentence built as "it's not X, it's Y".
- Rule-of-three padding, where a third item is there for rhythm rather than meaning.
- Ending a section on a punchy one-liner.
